# Hacker News Reader

Веб-приложение для просмотра топовых новостей с [Hacker News](https://news.ycombinator.com/). Показывает список свежих публикаций и страницу отдельной новости с деревом комментариев.

## Возможности

- Список топовых новостей с Hacker News
- Страница новости с заголовком, автором, датой и ссылкой на оригинал
- Комментарии с вложенной структурой
- Обновление списка новостей и комментариев по кнопке


## Запуск

### Режим разработки

```bash
npm run dev
```

Откройте в браузере адрес, который покажет Vite (обычно [http://localhost:5173](http://localhost:5173)).

### Сборка для продакшена

```bash
npm run build
```


## Как пользоваться

1. Откройте главную страницу — загрузится список топовых новостей.
2. Нажмите на заголовок новости, чтобы перейти на страницу с подробностями.
3. На странице новости можно:
   - вернуться к списку по ссылке «← К списку новостей»;
   - открыть оригинальную публикацию на Hacker News;
   - просмотреть комментарии;
   - обновить комментарии кнопкой «Обновить».
4. На главной странице кнопка «Обновить» перезагружает список новостей.
